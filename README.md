# Cotizaciones Proexcom

Página para armar cotizaciones rápidas de Proexcom S.A.S.: importar materiales desde Excel, pedir y comparar precios de proveedores, y descargar la cotización, la orden de compra y el informe de proveedores con el membrete de la empresa.

## Publicar en GitHub Pages

1. En github.com, crea un repositorio nuevo (por ejemplo `cotizaciones-proexcom`). Puede ser público o privado, según tu plan de GitHub.
2. En el repositorio, entra a **Add file → Upload files**, arrastra `index.html` y este `README.md`, y pulsa **Commit changes**.
3. Ve a **Settings → Pages**. En *Build and deployment* elige **Deploy from a branch**, rama **main**, carpeta **/(root)**, y pulsa **Save**.
4. En uno o dos minutos la página queda en `https://TU-USUARIO.github.io/cotizaciones-proexcom/`.

Para actualizarla, sube de nuevo el `index.html` en el mismo repositorio (reemplaza el anterior).

## Dónde quedan los datos

Las cotizaciones se guardan en el navegador del computador donde las haces. Para pasarlas a otro equipo, o por seguridad, usa **Datos de la empresa → Descargar respaldo** y luego **Cargar respaldo** en el otro equipo.

Nota: si el repositorio es público, cualquiera con el enlace puede abrir la página, pero no ve tus cotizaciones: esas solo existen en tu navegador.
